# kotosquare-

Koto Square コーポレートサイト TOPページ デザイン案（コンペ用）

- `docs/index.html` … PC版
- `docs/sp.html` … スマートフォン版（PCから見る場合は `sp.html?sp`）
- `design/` … 元のデザインデータ（Claude デザインキャンバス形式）
- `export/` … 提出用の画像（PC・スマホ・ヒーローの3段階）
- `handoff/` … 分析・改善計画の資料

※ 掲載している会社情報・実績・お知らせの内容はダミーです。検索エンジンには登録されないよう `noindex` を指定しています。
